# Gusti Adistriani — CV & Portfolio

Static, responsive one-page portfolio, ready for GitHub Pages.

## Publish
In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**.

## Edit
- `index.html`: profile, links, experience and other content.
- `styles.css`: typography, spacing and responsive layout.
- Image files: portfolio previews.

The website needs no server or build step. Google Fonts supplies Instrument Serif and Inter. All links use relative asset paths so both user and project Pages URLs work.
